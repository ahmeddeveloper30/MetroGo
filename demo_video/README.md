# Smart Metro (MetroGo) — Seminar Demo Video

**Deliverable:** `smart_metro_seminar_demo.mp4`
- 59.90s · 1920×1080 · 30 FPS · H.264 + silent AAC · faststart
- Every interaction is **real**: recorded live with Playwright driving system Chrome against the dev server (`http://localhost:5173`, mock backend).
- Arabic RTL caption pills with curved animated arrows are injected into the live page during recording; each caption replaces the previous one (sequential, no clutter).
- **No background music** (per approval) — the audio track is silent AAC.
- The admin dashboard is shown honestly as a coming-soon stub («مميزات قيد التطوير» / «هذه الصفحة قادمة في مرحلة لاحقة») — no fabricated functionality.

## How to rebuild
1. Start the dev server (`npm run dev`) with the mock backend enabled (the project's default dev mode).
2. `node recording_scripts/record_scenes.cjs record` — records all 8 scenes into `raw/`.
3. `node editing_scripts/build_video.cjs` — trims, retimes, crossfades and muxes the final MP4.
4. `node editing_scripts/qc_video.cjs` — automated spec check (expect "ALL CHECKS PASSED").

Scripts use `.cjs` because the package is `"type": "module"`. Recording needs system Chrome installed (Playwright `channel: 'chrome'`) and FFmpeg on PATH.
