# Fonts

The video uses **IBM Plex Sans Arabic** (weights 400/600/800), loaded from Google Fonts
(`<link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Arabic:wght@400;600;800&display=swap">`)
by `assets/intro.html`, `assets/closing.html` and the recorded web pages.

No font binaries are bundled in this repository (Google Fonts license requires
distribution as source, not as static copies here).
